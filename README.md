## GitHub'ga yuklash

GitHub'da yangi bo‘sh repository yarating va ushbu papkadagi **barcha fayllarni** repository'ga yuklang. Yoki terminaldan:

```bash
git init
git add .
git commit -m "feat: wedding invitation"
git branch -M main
git remote add origin YOUR_GITHUB_REPO_URL
git push -u origin main
```

## Vercel'ga joylash

1. Vercel → **Add New → Project**.
2. GitHub repository'ni tanlang.
3. Framework preset: **Other** (Vercel o‘zi static loyiha sifatida ham aniqlashi mumkin).
4. Build command va Output Directory'ni bo‘sh qoldiring.
5. **Deploy** bosing.

Taklifnomaning asosiy qismi uchun boshqa sozlama kerak emas.

## Mehmonlar tilaklari

### Darhol ishlaydigan rejim

Hech qanday sozlamasiz forma ishlaydi; yozilgan tilak browser `localStorage`ida saqlanadi. Demo tilaklar ham ko‘rsatiladi.

### Barcha mehmonlarga umumiy tilaklar (ixtiyoriy)

Agar barcha telefonlarda bir xil tilaklar ko‘rinishi kerak bo‘lsa, Supabase'da bitta jadval yarating:

```sql
create table public.wedding_wishes (
  id bigint generated by default as identity primary key,
  name text not null check (char_length(name) between 1 and 60),
  message text not null check (char_length(message) between 1 and 500),
  created_at timestamptz not null default now()
);

alter table public.wedding_wishes enable row level security;

create policy "public can read wishes"
on public.wedding_wishes for select
to anon
using (true);

create policy "public can add wishes"
on public.wedding_wishes for insert
to anon
with check (true);
```

Vercel Project Settings → Environment Variables ichida:

- `SUPABASE_URL`
- `SUPABASE_ANON_KEY`

ni kiriting va redeploy qiling. Kod o‘zgartirish shart emas.
